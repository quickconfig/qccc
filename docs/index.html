Compiler reference

Build, inspect, and format QuickConfig assets from the terminal.

QCCC is the command-line interface for QuickConfig. It compiles source files, decompiles binaries, formats projects, and reports diagnostics with clarity.

View commands See examples 
qccc compile app.qc
qccc decompile app.qbin
qccc fmt ./configs
qccc version

Overview

What QCCC helps you do

Compile sources

Turn QuickConfig source files into compact binary assets ready for loading or distribution.

Decompile binaries

Recover source-like output from compiled data so you can inspect or debug existing assets.

Format projects

Normalize one file or an entire folder of QuickConfig documents with a single command.

Commands

Core CLI actions

compile

Compile a target .qc file into a .qbin binary asset.

qccc compile app.qc

decompile

Reconstruct source-style output from a compiled QuickConfig binary. 

qccc decompile app.qbin

fmt

Format a file or directory of .qc assets in place.

qccc fmt ./configs

version and help

Inspect the build version or print the command reference.

qccc version
qccc help

Workflow

A practical development loop

01

Author your source

Create or update a QuickConfig document with the expected .qc syntax.

02

Compile and inspect

Use the compiler to produce a binary asset and review any diagnostics.

03

Format consistently

Run the formatter over your project to keep files readable and consistent.

04

Decompile when needed

Recover source-like output from binaries when you need to inspect existing assets.

Examples

Typical command sequences

Single-file round trip

qccc compile config.qc
qccc decompile config.qbin

Use this when you want to verify that the compiler and decompiler agree.

Format an entire project

qccc fmt ./src

Apply formatting across a directory without touching unrelated files.
